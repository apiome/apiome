## Preferences

Preferences are personal: they follow you to every workspace on this device.

1. **Press <Kbd keys="Mod+,"/>**, or **open your user menu and choose “Preferences”**.
2. On **Appearance**, pick a **Theme** — **Follow system**, **Light**, **Dark**, **High contrast**
   and five more — a **Font size** from **Small** to **Largest**, and a **Density**
   (**Comfortable** or **Compact**). Switches below turn on **Reduce motion**, **Collapse sidebar
   by default**, **Monospace for identifiers** and **Show keyboard hints**.
3. Changes save as you make them. **Click “Done”** to close.

**Account** links to your profile and linked sign-in accounts; **Notifications** chooses what
Apiome tells you about; **Shortcuts** lists the keyboard shortcuts.

## Keyboard

Every task in this guide can be done from the keyboard.

| Keys | Does |
| --- | --- |
| <Kbd keys="Mod+K"/> | Open the command palette — search or jump to anything, or run a command |
| <Kbd keys="?"/> | Show every shortcut (outside a text field) |
| <Kbd keys="/"/> | Search — opens the command palette's search field (outside a text field) |
| <Kbd keys="G"/> then <Kbd keys="H"/> | Go to Home (<Kbd keys="P"/> Projects, <Kbd keys="C"/> Catalog) |
| <Kbd keys="N"/> | New item on the current page |
| <Kbd keys="I"/> | Import |
| <Kbd keys="Mod+\"/> | Show or hide the sidebar |
| <Kbd keys="Esc"/> | Close a dialog or menu |

On Windows and Linux, read ⌘ as Ctrl. [Keyboard](../workspace/keyboard.md) has the keyboard path
for every task and the full reference; [Accessibility](../workspace/accessibility.md) covers
screen readers and themes.
