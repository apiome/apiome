Admin & tools is for the people who run an Apiome installation: the **admin console** (users,
tenants, licenses, feature flags, auth providers), the **data browser** and **migrations**.

To serve this site yourself, see [Host the documentation site](/admin/docs-image). More pages for this
group are on the way; until then, see the [runbooks](https://github.com/apiome/apiome/tree/main/docs/runbooks)
in the repository.
