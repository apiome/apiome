Bring in covers everything that starts outside Apiome: importing a specification, the **catalog**
of supported formats and connected **repositories**.

[How importing works](./how-importing-works.mdx) gives the overview: the sources, the preview-then-commit flow, bulk imports and import history. Then start with the [Catalog](./catalog.mdx) and the [Import wizard](./import-wizard.mdx);
[Repositories](./repositories.mdx) bring in whole repositories, and [Supported formats](./supported-formats.md) lists every format and which importer handles it. [Find APIs across formats](./find-apis-across-formats.md) shows how to filter, categorize and search them by protocol and format. [Keep imports up to date](./keep-imports-fresh.mdx) explains how each source stays current. The Connectors screens are not yet available.
