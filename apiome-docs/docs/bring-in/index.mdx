Bring in covers everything that starts outside Apiome: importing a specification, the **catalog**
of supported formats, connected **repositories** and **MCP servers**.

Start with the [Catalog](./catalog.mdx) and the [Import wizard](./import-wizard.mdx); [Repositories](./repositories.mdx)
and [MCP servers](./mcp-servers.mdx) bring in whole repositories and MCP servers, and
[Supported formats](./supported-formats.md) lists every format and which importer handles it.
