The **Apiome** MCP server (`apiome-mcp`) serves the published-spec catalog to MCP hosts. Run it with `apiome-mcp serve --transport stdio` for a desktop host, or `apiome-mcp serve --transport http` for streamable HTTP (port 8765 by default).

| Endpoint | Serves |
| --- | --- |
| `/mcp` | The catalog server documented here |
| `/agent/mcp` | The agent runtime: each agent toolset's compiled tools |
| `/health` | Liveness probe (HTTP 200; does not query Postgres) |
