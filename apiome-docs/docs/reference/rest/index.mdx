## Authentication

Endpoints that need a caller accept either of these schemes:

| Scheme | Type | Sent as | Description |
| --- | --- | --- | --- |
| `ApiKey` | apiKey | `X-API-Key` header | API key for tenant-scoped access (alternative to JWT) |
| `Bearer` | http | `Authorization: Bearer …` | JWT token from NextAuth (Authorization: Bearer &lt;token&gt;) |
