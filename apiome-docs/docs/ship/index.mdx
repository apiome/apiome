Ship is what happens after a version is ready: **publishing** it, planning its **sunset**, exporting
it in another format, generating an **SDK** and trying it against a **mock**.

Pages for this group are on the way. Until then, see the repository guides:

- [Publish a version](https://github.com/apiome/apiome/blob/main/docs/guide/publish-a-version.md)
- [Export a spec](https://github.com/apiome/apiome/blob/main/docs/guide/export-a-spec.md)
- [Portable mock runtime](https://github.com/apiome/apiome/blob/main/docs/guide/portable-mock-runtime.md)
