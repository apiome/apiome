Anything Apiome imports can be exported to any format it writes: an OpenAPI API as GraphQL, Protocol
Buffers, AsyncAPI, Avro, WSDL, SQL or a Postman collection, and back again. The full list, and which formats
round-trip, is on [Supported formats](../bring-in/supported-formats.md).

Formats don't all say the same things, so a conversion can lose detail. Apiome tells you **before** you
export: every target shows how much of your API it preserves, and every construct that is dropped,
approximated or invented is listed with the reason. Then the file is written, checked with the format's
own rules, and handed to you or delivered.

<Screenshot id="export-studio" alt="Export studio on the Target step: compact target tiles grouped by family, each with its three-segment fidelity meter" />

## When to use it

- **A consumer speaks another format.** A gRPC team wants `.proto`, a data team wants Avro or SQL, a
  partner wants WSDL, a front end wants GraphQL.
- **Moving from one format to another.** Convert an API, check what the new format can't hold, and fix it
  before you switch.
- **Publishing everywhere at once.** Export several formats or items in one job, keep the combination as a
  preset, and run it on every publish.

## How the pieces fit

- **One engine, every surface.** The dialog, the studio, Browse, the CLI, MCP and the API all start the
  same export job, with the same targets, options and fidelity report.
- **Fidelity first.** Each target shows a tier — **lossless**, **lossy** or **types-only** — and how much
  it preserves, worked out for *your* source. A lossy conversion asks you to acknowledge it, and a severe
  one to confirm it.
- **Checked before it leaves.** The written file is validated with the format's own parser or toolchain
  where the server has it, or by reading it back. A file that fails is never downloaded or delivered.
- **The workspace decides what may leave.** An export quality policy can warn about, or block, delivery
  when the source's lint grade or the conversion's fidelity is too low.
- **The format decides the rest.** Each target declares its options, whether it writes one file or a
  bundle, its pictures and its test-drive tools, and every surface picks them up from there.
