There are two ways to see what a mock answers before a consumer depends on it, from lighter to
heavier:

| Way | Where | Needs a running mock |
| --- | --- | --- |
| **Try it** — render one request without sending it | The **Scenarios** and **Correlation** editors | No |
| **Hosted mock** — call the version's mock URL | The **Mock** cell on [Published](./published.mdx) or Versions | Yes, turned on |

## Preview a response (Try it)

<Route path="/ade/dashboard/published" />

1. On **Published**, **click “Scenarios”** (or **“Correlation”**) in a version's **Mock** cell.
2. Under **Try it**, **choose an operation** — `GET /pets` — and fill in any parameters.
3. **Click “Render”.** You see the status, headers and body the mock would return, and a trace naming
   the layer that answered — a scenario and its rule, correlation or the spec's example.

Nothing is saved and nothing is sent: the preview uses the editor's unsaved draft, so you can try a
change before **Save scenarios**. Latency and chaos are reported rather than applied. Details are in
[Mock response preview](../reference/mock-runtime/mock-response-preview.md).

## Call the hosted mock

Turn on the version's mock on [Published](./published.mdx#the-hosted-mock), **copy its URL** and
call it. Send `X-Mock-Scenario: <name>` to pick a scenario:

```bash
curl https://mock.apiome.dev/acme/payments-api/2.3.1/payments
curl -H 'X-Mock-Scenario: quota-exceeded' https://mock.apiome.dev/acme/payments-api/2.3.1/payments
```

The **Mock** cell's sparkline counts the requests over 30 days.

## With the CLI or the API

- CLI: `apiome mock preview <project> <version> -X GET --path /pets/42` renders a request like **Try
  it**; `apiome mock run BUNDLE` serves a version offline — see
  [Portable mock runtime](../reference/mock-runtime/portable-mock-runtime.md).
- REST: `POST /v1/versions/{tenant}/{project_id}/{version_record_id}/mock/preview` (Try it);
  `POST /v1/export/{tenant}/mock`, `GET /v1/export/{tenant}/mock/{mock_id}/requests` and
  `DELETE /v1/export/{tenant}/mock/{mock_id}` (a short-lived mock of an exported file) — see the
  [API reference](../reference/api-reference.md).
