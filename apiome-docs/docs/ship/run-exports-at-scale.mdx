One export is a few clicks in the [Export studio](./export-studio.mdx). A team that exports every day
needs more: to see each job as it runs and get it back on track when it fails, to know **who exported
what, where, and with how much loss**, to send the result where it is used, to run the same export on
every publish, and to understand every screen when something is missing. This page shows where each of
those lives.

<Screenshot id="export-studio-history" alt="The History tab: two runs, a Petstore export to Protocol Buffers that completed with 64% preserved, valid, lint warnings and delivered to git, and an Orders export to GraphQL that failed" />

## When you need it

- **A long export, or one that failed.** Follow its stages, cancel it, retry it, or come back to it
  after leaving the page.
- **An audit question.** Who exported this version, to which format, with how much loss, and where it
  was delivered — for 90 days, filtered by person, source, format or outcome.
- **The result belongs somewhere else.** A git pull request, a webhook, a bucket or a schema registry,
  with what each delivery left behind.
- **The same export again and again.** Save it as a preset, and run it on every publish of a project.

## How the pieces fit

- **One job, everywhere.** Generate, a preset, the CLI and an auto-export all run the same export job.
  Each one appears in **Recent export jobs** while it is recent, and in **History** for 90 days.
- **History is the record.** It keeps each run's outcome, its share preserved, its validation, lint and
  delivery verdicts, and every delivery's result. It never stores the exported file. **Re-run in Studio**
  opens the studio with that run's source, version, target and options.
- **Delivery uses profiles.** A profile saves a destination and its credentials once. The studio, presets
  and auto-exports all deliver through profiles, and the credentials never reach the browser.
- **A preset is what the studio had.** It keeps the targets, the options you changed and every ticked
  delivery profile, in order, so applying it gives back the same export. **Auto-export on publish**
  subscribes a project to the preset you just saved or applied.
- **Nothing is ever blank.** Each step says when it is loading, has nothing to show, or failed, and
  offers **Retry** or the next step. If the export targets can't be reached, the last list stays on
  screen, marked as possibly out of date.
