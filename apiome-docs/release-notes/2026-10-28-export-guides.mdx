The [Export studio](/ship/export-studio) guide is back on the site, and a new page,
[Export catalog items](/ship/export-catalog-items), puts every way to export a catalog item side by
side. The studio itself opens with the Catalog Exporter release.

{/* truncate */}

- **Export studio.** All five steps, opening the studio with no source and picking one, several
  targets in one archive, lint of the emitted file on **Verify**, failures and the quality-policy
  gate, the keyboard path and who can export. Gateway push-back and **SDK & branding** stay out of
  the guide until their features ship.
- **Export catalog items.** The **Export** dialog, the studio, bulk export from the Catalog's bulk
  bar and the CLI, with a table of every target's fidelity tier for a REST API, an RPC service, an
  event API and a set of types. The table is generated from the export registry, so it changes when
  a target does.
- **Back where they were.** [Mock try-out](/ship/mock-try-out#test-drive-an-export) has its
  **Test-drive an export** section again, and [Browse and export](/getting-started/browse-and-export),
  [Keyboard](/workspace/keyboard), [Accessibility](/workspace/accessibility),
  [Roles](/workspace/roles), Versions and the Catalog link to the studio.
