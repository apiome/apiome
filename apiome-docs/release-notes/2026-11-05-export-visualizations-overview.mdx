The Export studio's **6. Review & Generate** step can now show a generated file as pictures as well as
text: where it loses fidelity, and its structure as tables, files, services or channels. See
[Visualize an export](/ship/visualize-an-export).

{/* truncate */}

- **Where it loses fidelity:** the mapping graph wears the fidelity report, each entity marked with its
  worst finding, filtered by kind, with a treemap for large APIs.
- **Database exports as an ERD:** tables, columns, keys and foreign keys, with made-up keys and junction
  tables marked.
- **Protocol Buffers and Connect RPC:** an import graph of the bundle's files and a service map of its
  services, methods and messages.
- **AsyncAPI and xRegistry:** a channel topology of operations, channels and messages, or message groups and
  event types.
- **One selection:** every picture, the entity tree and the file select the same part of your API.
