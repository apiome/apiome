The docs now have one overview page for Apiome's import system.
[How importing works](/bring-in/how-importing-works).

{/* truncate */}

- **The flow:** every import is analyzed and previewed before you commit it, runs as a job, and
  records where it came from.
- **Every source in one table:** files, archives, URLs, pasted text, Git repositories, SwaggerHub,
  live endpoints and gateway exports such as AWS API Gateway.
- **Import several specs at once:** how **Import to catalog** splits an archive or repository folder
  into independent specs and imports them all, now documented step by step.
- **Import history:** the recent imports on the wizard's first step, **Recent import jobs**, a
  repository's page and a catalog item's **Provenance** tab.
