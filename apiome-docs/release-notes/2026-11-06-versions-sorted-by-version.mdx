---
slug: versions-sorted-by-version
title: Versions are listed by version number, with the latest marked
description: "Versions sorts by version number by default and marks the highest (latest)."
authors: [apiome]
---

The **Versions** page now lists a project's versions by version number, highest first, instead of
by the date they were created. The highest version reads **(latest)** beside its number, in the
**Timeline** and the **Table**, even when a filter hides other versions. **Sorted by** still
switches to created date or any other column. See [Versions](/build/versions).
