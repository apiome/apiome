OData export is complete: the CSDL emitter, its fidelity pack, validation against the OASIS
schemas, and the **OData** target card, CLI and fixtures.
[OData (CSDL) from any source](/ship/export-a-spec#odata-csdl-from-any-source) now opens with an
overview of all of it.

{/* truncate */}

- **When to export to OData:** to describe a REST, RPC, GraphQL, JSON Schema or WSDL item as an
  OData service, with entity types, keys, entity sets, Functions and Actions, or to round-trip an
  OData item losslessly.
- **At a glance:** one table from the **OData** card and its output, through how the item is written
  and what the fidelity report lists, to the checks before every download and the CLI.
