**Connectors** is released for RC8, which opens with the MCP expansion work. It is back in the
sidebar's **Bring in** section, between **Repositories** and **MCP servers**, and in the command
palette. Its pages — the connector list, **Add connector**, each connector's
items, runs, environments and settings — open for every member instead of showing **Not available
yet**. See [Connectors](/bring-in/connectors).

{/* truncate */}

- **Every source kind.** Kong Konnect and Kong Admin, AWS API Gateway, Azure API Management,
  Apigee, a schema registry, an [MCP registry](/bring-in/connectors#mcp-registry), a specification
  URL and a [registry crawl](/bring-in/connectors#registry-crawl) sync their APIs into the catalog —
  an MCP registry's servers into **MCP servers**.
- **The places that point to it link again.** **Repositories** shows **Recent runs** of Git
  refreshes and connector syncs together, the catalog's **Source** filter offers **Catalog
  connector**, a synced item's **Provenance** names its connector, and an MCP registry import's
  last step offers **Open the connector**.
- **Its guide is back.** [Connectors](/bring-in/connectors) returns, with links from
  [Repositories](/bring-in/repositories), [Catalog](/bring-in/catalog), the gateway import pages and
  [Export to a gateway](/ship/export-to-a-gateway).
- **Still held back:** **Shadow APIs**, the **Dependency graph**, **Teams** and the **Schema
  registry**. Where the Connectors guide mentions them it links to their REST reference.
- **The screenshots show it.** The Connectors screenshots are back, and the Repositories, menus,
  Preferences, command palette and theme samples are recaptured with **Connectors** in the sidebar.
