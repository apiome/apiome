Creating an account has its own page: **`/signup`**. Link to it from anywhere — a website, a
docs page, an email. **Create one** on the sign-in page now opens it too.
[Create an account](/getting-started/create-an-account).

{/* truncate */}

- **Every way in, on one page.** **Sign up with …** for each sign-in provider the installation
  offers, then the email and password form, and **Already have an account? Sign in**.
- **Follows the sign-up policy.** When sign-up is closed or by invitation, the page says so and
  offers only the sign-in link — no buttons that would not work. When sign-up is limited to some
  email domains, the page names them.
- **Terms and privacy only when they exist.** The *By creating an account, you agree to…* line links
  the pages an administrator configures (`APIOME_TERMS_URL`, `APIOME_PRIVACY_URL`), and is left out
  when there are none — on the sign-in page too.
