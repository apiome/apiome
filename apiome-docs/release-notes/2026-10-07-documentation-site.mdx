Apiome has a documentation site. It is grouped by the job you are doing — Getting started, Build,
Bring in, Ship, Govern, Workspace & account, Admin & tools and Reference — follows your system's
light or dark theme, and is searchable from the navbar. ([#67](https://github.com/apiome/apiome/issues/67))

{/* truncate */}

The existing guides move onto the site over the RC6 documentation epic, together with screenshots of
every screen that regenerate from the product, generated REST / CLI / MCP reference and a release-notes
page per release.
