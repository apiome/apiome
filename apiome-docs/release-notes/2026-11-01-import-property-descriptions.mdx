The import wizard's **Preview** step lets you add or change property descriptions before anything is
imported. The [import wizard guide](/bring-in/import-wizard#change-property-descriptions) now explains
how.

{/* truncate */}

- **Property descriptions** lists every property of the schemas you ticked, with the spec's own
  description as a hint.
- Type a description to replace the spec's in the imported project; leave a box empty to keep it.
