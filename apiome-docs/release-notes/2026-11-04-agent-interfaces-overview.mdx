The agent-interface exports are complete: MCP tool definitions, the A2A Agent Card, the
`agents.json` and `llms.txt` manifests on Browse, their fidelity reports, and the target cards, CLI and
fixtures. [Agent interfaces](/ship/export-a-spec#agent-interfaces) brings them together.

{/* truncate */}

- **When to use which:** MCP tool definitions when an agent should call the API, an A2A Agent Card when
  the API should be offered as an agent (or an A2A agent republished), and the Browse manifests so
  agents and crawlers can find every public API.
- **At a glance:** the three side by side — what each is made from, what you get, the options, what
  an operation becomes, the grouping guard, what checks it, how it imports back, the CLI command and
  where to find it.
