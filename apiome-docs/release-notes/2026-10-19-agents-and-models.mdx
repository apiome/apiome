Register the AI agents that call your APIs and the models they run on. An agent becomes a consumer
of every API its keys can call, so breaking-change impact, the blast radius and the dependency graph
include it.

{/* truncate */}

- **Agents.** Register one from **Bring in → Catalog → Agents** with its runtime, model and agent
  keys. Its page shows the owner team, each key's name, prefix and status (never the secret), what
  it consumes per API, its usage and its dependency graph. **Retire** stops it consuming anything.
- **Consumers, derived.** For each API its keys reach, the agent gets a consumer and a contract
  with one operation per enabled, allowlisted tool. Revoking or unlinking a key records a new
  contract and the dropped `consumes` edges go stale.
- **Models.** Record provider, version, hosting and data handling, and a deprecation date that
  every agent running on the model shows.
- **API.** `/v1/tenants/{tenant}/catalog-agents` and `/catalog-models`; agents and models are also
  catalog kinds (`?kind=agent`, `?kind=model`), can have owner teams, and the agent usage page links
  each key to its agent.

See [Agents and models](/reference/rest/catalog-agents).
