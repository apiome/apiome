A new page, [What an import records](/bring-in/what-an-import-records), lists what Apiome stores
with every imported version, whatever its format, and where you see each record.

{/* truncate */}

- **Four records.** The format, the protocol, the tool versions that read the source and the format
  metadata: where the source came from, why it was routed where it was, its fingerprint, the kept
  source, what the secret scrub removed and the settings a re-upload replays.
- **Where you see them.** The four steps of a catalog item's **Provenance** tab, what each says when
  nothing was recorded, and the `sourceFormat`, `protocol`, `formatMetadata` and `toolVersions`
  fields over REST.
- **Older versions.** How versions from before these records were tagged with a format and protocol,
  and what was left as it was.
