The `apiome` CLI installer is served at [get.apiome.dev](https://get.apiome.dev). **Download the CLI
here**, then run it with `sh`, or pipe it straight in with `curl -fsSL https://get.apiome.dev | sh`.
See [Install the CLI](/reference/install-the-cli).

{/* truncate */}

- **Where:** the [Install the CLI](/reference/install-the-cli) page now links to the download at the
  top. The apiome.dev home page and footer link to it too.
- **What you get:** the same `apiome-cli/install.sh` from the Apiome repository, refreshed from `main`
  every 15 minutes.
