AsyncAPI export is complete: the emitter, its fidelity pack, AsyncAPI 3.1, 3.0 and 2.6, validation
with the AsyncAPI parser, and the **AsyncAPI** target card, CLI and fixtures.
[AsyncAPI 3.1, 3.0 and 2.6](/ship/export-a-spec#asyncapi-31-30-and-26) now opens with an overview
of all of it.

{/* truncate */}

- **When to export to AsyncAPI:** to round-trip an event API losslessly, to describe a REST or RPC
  API as messages (each request / response becomes a `send` with a `reply`), or to serve consumers
  on AsyncAPI 3.0 or 2.6.
- **At a glance:** one table from the **AsyncAPI** card under **Events** and its fidelity report,
  through the parser check, to the CLI.
