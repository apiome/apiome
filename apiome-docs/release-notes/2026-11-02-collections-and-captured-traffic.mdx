The docs now have one overview page for importing the APIs your team already calls from an API
client or has recorded. [Collections and captured traffic](/bring-in/collections-and-captures).

{/* truncate */}

- **Every source in one table:** HAR captures, Postman, Insomnia, Bruno, Hoppscotch and Thunder
  Client collections, and `.http` / `.rest` request files, each linked to its own page.
- **How it works:** credentials are removed before anything is stored, one shared engine infers the
  operations and schemas from the requests, and the result lands in the Catalog labelled
  **inferred** until you convert it to OpenAPI.
- **Better results:** how more samples give a fuller API, and how to export it back to an API
  client.
