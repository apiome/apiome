title: Format import guides have their own submenu
description: The Bring in sidebar groups the per-format import guides under API formats.
authors: [apiome]
---

The **Bring in** section of the user guide's sidebar now lists its general pages — the catalog, the
import wizard, repositories, importing a specification, supported formats and converting to OpenAPI
— followed by one collapsed **API formats** submenu that holds every per-format import guide.

{/* truncate */}

- **Why:** each format had its own entry in **Bring in**, so the list ran to dozens of items and
  pushed **Ship**, **Govern** and **Workspace & account** far down the sidebar.
- **What changes for you:** open **API formats** to find a format's import guide; it opens by itself
  when you are reading one. Page addresses are unchanged, so existing links and bookmarks still work.
