The modern RPC and event formats are complete: OpenRPC, CloudEvents and xRegistry, Apache Thrift,
FlatBuffers and Cap'n Proto, Connect RPC, and the REST hypermedia conventions with JSON Type
Definition. A new guide, [RPC and event formats](/bring-in/rpc-and-event-formats), brings them
together.

{/* truncate */}

- **What you can import:** one table of every format, what it is, its importer and its own page.
- **How it works:** importing a file or a set, reading OpenRPC, Connect and xRegistry from a running
  service, comparing versions by each format's rules, its lint pack, and converting to OpenAPI.
- **Going the other way:** each format is an export target too.
