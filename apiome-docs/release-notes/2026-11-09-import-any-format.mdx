Multi-format import is complete: Apiome brings in gRPC, GraphQL, AsyncAPI, OData, Avro, WSDL, TypeSpec,
RAML, API Blueprint, Smithy, agent descriptors, RPC and event formats, and healthcare, finance and EDI
standards next to OpenAPI. The new [Import and catalog any format](/bring-in/import-any-format) page is
the map.

{/* truncate */}

- **Every source:** the Import wizard, live endpoints, connected repositories, schema registries and the
  CLI all run the same analyze, preview and commit flow.
- **Kept in its own format:** each catalog item keeps its structure, read into one model underneath so it
  can be searched, compared and linted like any other API.
- **Versions and lint per format:** revisions are fingerprinted and compared in the format's own terms,
  and each format has its own rule pack, score and grade.
- **Found by protocol:** REST, RPC, Event, Graph, Data Schema and Agent are filters on the Catalog, in
  search and on Browse; convert an item to OpenAPI or export it to another format when you need to.
