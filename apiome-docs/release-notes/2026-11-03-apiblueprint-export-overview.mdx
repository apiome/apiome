API Blueprint export is complete: the emitter, its fidelity pack, validation with drafter, and the
**API Blueprint** target card, CLI and fixtures.
[API Blueprint from any source](/ship/export-a-spec#api-blueprint-from-any-source) now opens with an
overview of all of it.

{/* truncate */}

- **When to export to API Blueprint:** to publish a REST item as human-readable Markdown docs, or to
  round-trip an API Blueprint item losslessly. It is documentation, not a contract, so prefer
  OpenAPI for a machine-readable one.
- **At a glance:** one table from the **API Blueprint** card and its options, through how the item is
  written and what the fidelity report lists, to the drafter check before every download and the CLI.
