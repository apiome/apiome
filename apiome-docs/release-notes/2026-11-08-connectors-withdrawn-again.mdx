RC8 starts with the MCP expansion work, so **Bring in** lists **Catalog**, **Repositories** and
[**MCP servers**](/bring-in/mcp-servers), the catalog of the MCP servers Apiome knows about.
**Connectors**, released earlier today, is withdrawn again until a later release.

{/* truncate */}

- **Not in the sidebar or ⌘K.** A bookmark to a connector page opens **Not available yet**.
- **Places that pointed to it.** **Repositories** no longer shows **Recent runs**, the catalog's
  **Source** filter no longer offers **Catalog connector**, and an MCP registry import no longer
  links to its connector.
- **The guide.** The Connectors page is off the site again; pages that mentioned it link to the
  REST reference instead.
