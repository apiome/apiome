RAML import is complete: parsing and resolving with AMF, the canonical model with resource types and
traits applied, the lint pack, the breaking-change rules, and the source card, CLI and the move to
OpenAPI. [Import a RAML API](/bring-in/raml-import) now opens with an overview of all of it.

{/* truncate */}

- **When to use it:** an existing RAML 1.0 API, one file or a set with its `!include`s and `uses`
  libraries, to catalog, lint and diff it before moving it to OpenAPI.
- **At a glance:** one table from importing and what is resolved, through refused sets, lint and
  comparing versions, to migrating to an OpenAPI 3.1 project and exporting back to RAML, each linked
  to its section.
