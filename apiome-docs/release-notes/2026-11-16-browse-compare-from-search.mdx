With **All published** on, Browse search shows the same operation once per version — and turning
two of them into a diff used to take four clicks and a URL edit. Now it takes one.

{/* truncate */}

- **Compare from search.** **Version**, **Operation** and **Schema** results carry a **Compare**
  tick (or press <kbd>c</kbd> on the selected result). Tick two of one project and the bar under the
  results offers **▸ Compare v1.0.0 → v2.0.0**, opening the project's compare page at those versions.
  Picks from different projects, two picks from one version, and a third pick are refused with a
  message.
- **Switch versions on a result.** A result's version chip opens a menu of the project's other
  published versions. Each lands on the same operation or schema in that version when it exists
  there; otherwise it is marked *not in this version* and opens the version page.

See [Compare from search](/ship/browse-published-specs#compare-from-search).
