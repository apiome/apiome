Four tools for working on an API with other people are now complete, and one page maps them:
[Team workflows](/build/team-workflows).

{/* truncate */}

- **Presence and soft locks.** Avatars on **Versions** show who else has a project open, and
  **“… is editing this”** beside an element asks before you overwrite a colleague.
  [More](/build/presence-and-soft-locks)
- **Suggested changes.** A reviewer proposes an exact edit on the review's **Suggestions** tab; the
  author **clicks “Apply”**. A suggestion that went out of date is marked **Stale** rather than
  misapplied. [More](/govern/reviews#suggested-changes)
- **Draft branches and merge requests.** Change an API on a branch of its own, get it reviewed, and
  **click “Merge into main”** — behind the Git-like switch. [More](/build/merge-requests)
- **Consumer feedback.** Readers signed in to Browse send feedback from a version's **Feedback**
  tab; it lands in **Discussion** tagged **Consumer**, and your replies reach them.
  [More](/ship/send-feedback-on-an-api)
