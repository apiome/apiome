The standalone XSD export is complete: the XML Schema emitter, its fidelity report, RELAX NG and DTD
output, the ISO 20022 message profile, the checks before every download, and the card, CLI and Browse
delivery. [XSD (XML Schema) on its own](/ship/export-a-spec#xsd-xml-schema-on-its-own) now opens with an
overview of all of it.

{/* truncate */}

- **When to export to XSD:** a schema for an XML pipeline or JAXB code from any item, a lossless round
  trip for an imported XSD, RELAX NG or a DTD for older toolchains, and ISO 20022 message definitions for
  payments.
- **At a glance:** one table from the card and its options through the fidelity report, the two output
  variants and the checks to the CLI and Browse, each linked to its section.
