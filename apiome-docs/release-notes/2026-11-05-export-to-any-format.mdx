Multi-format export is complete: anything Apiome imports can be exported to any format it writes, and you
see what survives before you export. The new [Export to any format](/ship/export-to-any-format) page is
the map.

{/* truncate */}

- **Every surface:** the Export dialog, Export studio, the public Browse portal, the CLI, MCP and the REST
  API all run the same export job.
- **Fidelity first:** each target shows lossless, lossy or types-only, and how much of your API it keeps,
  with every dropped, approximated or invented construct and why.
- **Checked, then delivered:** every file is validated before it leaves; download it, deliver it to git,
  a webhook or a bucket, or register it on a schema registry.
- **At scale:** several formats or items in one job, presets, auto-export on publish, and a 90-day
  history.
