TypeSpec export is complete: the emitter, its fidelity pack, validation by compiling with `tsp`, and
the **TypeSpec** target card, CLI and fixtures.
[TypeSpec from any source](/ship/export-a-spec#typespec-from-any-source) now opens with an overview
of all of it.

{/* truncate */}

- **When to export to TypeSpec:** to move a REST, RPC, GraphQL, JSON Schema or WSDL item to one
  `.tsp` file that compiles, or to round-trip a TypeSpec item losslessly.
- **At a glance:** one table from the **TypeSpec** card and its options, through how the item is
  written and what the fidelity report lists, to the compile check before every download and the
  CLI.
