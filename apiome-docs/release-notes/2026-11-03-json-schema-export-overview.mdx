JSON Schema export is complete: the emitter, its fidelity pack, the JSON Type Definition
(RFC 8927) mode, validation and round-trip, and the **JSON Schema** target card, CLI and fixtures.
[JSON Schema from any source](/ship/export-a-spec#json-schema-from-any-source) now opens with an
overview of all of it.

{/* truncate */}

- **When to export to JSON Schema:** to share an item's data types on their own (validation
  pipelines, Kafka JSON subjects, config contracts), to target a `draft-07` or `draft-04` validator,
  to generate strict code from a JTD document, or to round-trip a JSON Schema item losslessly.
- **At a glance:** one table from the **JSON Schema** card and its options, through how the item is
  written and what the fidelity report lists for the draft you pick, to JTD mode, the checks before
  every download and the CLI.
