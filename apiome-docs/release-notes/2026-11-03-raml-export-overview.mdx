RAML export is complete: the emitter, its fidelity pack, validation with AMF, and the **RAML**
target card, CLI and fixtures.
[RAML from any source](/ship/export-a-spec#raml-from-any-source) now opens with an overview of all
of it.

{/* truncate */}

- **When to export to RAML:** to supply a tool that still reads RAML 1.0 with a REST item, or to
  round-trip a RAML item losslessly. RAML describes REST only, so prefer OpenAPI for new work.
- **At a glance:** one table from the **RAML** card and its options, through how the item is written
  and what the fidelity report lists, to the AMF check before every download and the CLI.
