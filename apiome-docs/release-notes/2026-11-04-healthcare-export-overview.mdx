The healthcare exports are complete: FHIR StructureDefinition logical models (R4 / R5) with their fidelity
pack and the official FHIR validator, the HL7 v2 segment guide, and the healthcare target cards, CLI and
fixtures. [Healthcare exports](/ship/export-a-spec#healthcare-exports) brings them together.

{/* truncate */}

- **When to use which:** FHIR for a FHIR server or profile author, the HL7 v2 segment guide for an interface
  partner's integration engine, HL7 v2 to write an imported message back out.
- **At a glance:** the three side by side — what each exports from, the files you get, the options, what enums
  become, how operations are handled, what checks it, and the CLI command.
- **One family:** in **Export studio**, the **HL7 v2 segment guide** card now sits under **Healthcare** with
  **FHIR** and **HL7 v2**.
