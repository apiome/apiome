OpenRPC export is complete: the emitter, its fidelity pack, validation against the OpenRPC
meta-schema and round-trip, and the **OpenRPC** target card, CLI and fixtures.
[OpenRPC from any source](/ship/export-a-spec#openrpc-from-any-source) now opens with an overview
of all of it.

{/* truncate */}

- **When to export to OpenRPC:** to describe a gRPC, REST, GraphQL or event API as JSON-RPC 2.0
  methods and notifications for the JSON-RPC ecosystem, or to round-trip an OpenRPC item losslessly.
- **At a glance:** one table from the **OpenRPC** card, through how the item is written and what the
  fidelity report lists, to the meta-schema check before every download and the CLI.
