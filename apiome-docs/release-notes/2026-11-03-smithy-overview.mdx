Smithy import is complete: assembling models into a JSON AST with the Smithy CLI, the canonical model
with traits and resources, Smithy validation and `smithy-linters`, `smithy diff` for breaking
changes, and the source card, CLI and fixtures.
[Import a Smithy model](/bring-in/smithy-import) now opens with an overview of all of it.

{/* truncate */}

- **When to use it:** any Smithy 2.0 model, `.smithy` IDL or JSON AST, one file or split across many.
- **At a glance:** one table from importing a file or a multi-file model and what the catalog item
  holds, through lint, comparing versions with `smithy diff` and refused models, to converting to
  OpenAPI and exporting back to Smithy, each linked to its section.
