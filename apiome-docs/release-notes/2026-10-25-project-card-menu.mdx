On **Projects**, each card's **⋯** menu now sits in the card's header row, right after the
status pill (*Active*, *Disabled*), and is always visible.

{/* truncate */}

It used to appear only on hover, as an overlay in the card's top-right corner, where it covered the
status pill. The menu's items are unchanged.
