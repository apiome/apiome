Two small fixes from the quiet pass. The **Import specification** wizard no longer opens as a
full-height sheet, and the **Profile** hero drops the app's last gradient.
[The Import wizard](/bring-in/import-wizard).

{/* truncate */}

- **The import wizard fits its step.** It opens at a standard wizard width and is as tall as the
  step needs, so the source cards are no longer followed by an empty half-screen.
- **Recent imports on the first step.** When you have imported before, the three most recent
  imports are listed under the source cards with their state; **All import jobs** opens the full
  list.
- **Continue.** The wizard's forward button reads **Continue** where it used to read *Next →*.
- **A flat profile hero.** The band at the top of **Profile** is a plain surface behind the hex
  avatar.
