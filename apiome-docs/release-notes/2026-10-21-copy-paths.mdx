When you copy from an existing version, **New version** now asks whether to **Copy paths** too.
[How copying works](/build/version-dialogs#copy-paths).

{/* truncate */}

- **Paths come along by default.** Operations, parameters, request bodies, responses and each path's
  Studio canvas are copied, pointing at the new version's classes.
- **Or start from the schemas only.** Untick **Copy paths** to keep the classes and leave the paths
  behind. Classes are always copied, because paths depend on them.
- **In the API.** `POST /v1/versions/{tenant_slug}/{project_id}` takes `copyPaths` with
  `source_version_id` — see the [Versions reference](/reference/rest/versions).
