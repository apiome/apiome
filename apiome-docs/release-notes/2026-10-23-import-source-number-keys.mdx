Press **`I`** on a list page to open **Import specification**, then **`1`** – **`5`** to choose
one of the first five sources — **File Upload**, **URL Import**, **Clipboard Paste**, **Git
Repository** and **SwaggerHub**. [The Import wizard](/bring-in/import-wizard).

{/* truncate */}

- **Each card shows its number** at the end of its title.
- **The keys work only on the first step.** Once a source's intake is open, a digit types as
  usual, and the keys never fire while you are typing in a field or holding `⌘`, `Ctrl` or `Alt`.
- **The shortcut sheet lists them** (press **`?`**) while the first step is open.
