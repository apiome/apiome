**MCP servers** is released: it is back in the rail's **Bring in** section, in the command palette
and the `G` shortcuts, and its pages — the server catalog, each endpoint, the capability directory,
analytics, server comparison and **Agent access** — open for every member instead of showing **Not
available yet**. See [MCP servers](/bring-in/mcp-servers) and [Agent access](/bring-in/agent-access).

{/* truncate */}

- **The places that point to it link again.** Home's quick actions offer **Register an MCP server**,
  a finding raised on an MCP server in Lint posture links to it, and a connector entry that added an
  MCP server opens that server.
- **Its guides are back.** [MCP servers](/bring-in/mcp-servers) and
  [Agent access](/bring-in/agent-access) return, with the **Add MCP server** wizard, **Postman
  Collection** and **MCP Server** sources on [Import wizard](/bring-in/import-wizard), and links from
  [API keys](/workspace/api-keys#agent-keys), [Tenants](/workspace/tenants) and the
  [MCP reference](/reference/mcp).
- **The screenshots show it.** The guide's MCP screenshots are recaptured, and so are Home, the
  command palette, the menus, Preferences and the theme samples, whose sidebar now lists **MCP
  servers** under **Bring in**. An endpoint's **Dependencies** tab stays hidden until the
  dependency graph is released.
- **The version badge reads RC8.** An unstamped build's badge on the home page, in the user menu and
  on **Help & docs** now reads `v<version> RC8`.
