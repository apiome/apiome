The build badge on the home page, in the user menu and on **Help & docs** now reads
`v<version> RC7` instead of `v<version> RC`.

{/* truncate */}

- **Why:** the badge said only "RC", so a support request did not say which release candidate the
  reader was on.
- **What changes for you:** nothing to do. The **What's new** dot reappears once, because it tracks
  the badge you last read the notes for.
