[Export to any format](/ship/export-to-any-format#specs-api-clients-diagrams-and-documents) now has one
table for everything a version can go out as, besides another specification format.

{/* truncate */}

- **The specification itself:** an OpenAPI 3.1 document, or 3.2, 3.0 or Swagger 2.0, from every export
  surface.
- **API clients:** a Postman collection, or a Bruno, Insomnia, Hoppscotch or Thunder Client one.
- **Diagrams:** the Export studio's pictures of what an export keeps, and the **Convert to OpenAPI**
  projection graph, which **Copy Mermaid** copies as Mermaid text.
- **Documents:** a migration guide as Markdown or PDF, and an approved change report as a PDF.
- **Not yet available:** PlantUML, and saving the schema canvas as an image, a PDF or a diagram file.
  [Understand export fidelity](/ship/export-fidelity) no longer lists those as export targets.
