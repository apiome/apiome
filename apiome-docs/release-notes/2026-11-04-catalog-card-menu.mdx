title: Catalog cards no longer hide the status behind the menu
description: "The catalog card's actions menu sits beside the status pill."
authors: [apiome]
---

On the **Catalog**, each card's ⋯ actions menu now sits in the card's header row, after the status pill,
and is always visible. It used to appear on hover in the card's corner, on top of the **Active** pill. See
[Catalog cards](/bring-in/catalog).

{/* truncate */}

The project cards got the same fix earlier: the pill and the menu share the row, so they can never overlap,
and the menu no longer needs a hover to be found on a touch screen.
