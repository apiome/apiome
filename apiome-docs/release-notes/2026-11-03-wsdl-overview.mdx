SOAP / WSDL import is complete: parsing with import resolution across files, the canonical model
with faults and SOAP bindings, live discovery, the WS-I Basic Profile checks, SOAP and XML Schema
breaking-change rules, and the source card, CLI and fixtures.
[Import a SOAP / WSDL service](/bring-in/wsdl-import) now opens with an overview of all of it.

{/* truncate */}

- **When to use it:** any SOAP service, WSDL 1.1 or 2.0 with SOAP 1.1, SOAP 1.2 or HTTP bindings,
  as one file, a set of files that import each other, or a running service.
- **At a glance:** one table from importing a file, a file set or a live service, through the WS-I
  checks and comparing versions by SOAP and XML Schema compatibility, to converting to OpenAPI and
  exporting back to WSDL and XSD, each linked to its section.
