RC9 is complete. Everything it shipped, from the app's **What's new** and the REST API, is in the
[Apiome RC9](/release-notes/rc9) release notes. The build badge now reads `v<version> RC10`.

{/* truncate */}

- **What RC9 brought:** Projects and the Catalog agree on every import, OpenAPI 3.2, 3.1, 3.0 and
  Swagger 2.0 and Arazzo 1.0 and 1.1 work end to end, lint findings with a safe fix are fixed in
  one click, every export names what it changes, and documents are stored once and read back. The
  [Projects, Catalog, OpenAPI and Arazzo](/getting-started/projects-catalog-openapi-arazzo) page
  maps it.
- **Why:** RC10 opens. It is about **contracts**: Pact Broker and PactFlow compatibility,
  bi-directional contract testing, and contract agreements with SLAs, data sharing and billing.
- **What changes for you:** **What's new** starts again for RC10, and its dot appears once, because
  it tracks the badge you last read the notes for. The launcher's **Recently shipped** card lists
  RC10 work as it lands. For what RC9 brought, open the [Apiome RC9](/release-notes/rc9) post.
