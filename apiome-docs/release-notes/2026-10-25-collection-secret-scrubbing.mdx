title: Credentials never leave a collection import
description: Secret scrubbing is always on for collections, captures and request files.

Postman, Insomnia, Bruno, HAR and `.http` imports now always strip credentials, whatever your
workspace's scrub policy says. Auth is kept as security-scheme stubs.
[How it works](/bring-in/collection-secret-scrubbing).

{/* truncate */}

- **Always on.** These five formats always run in enforce mode with entropy detection. The scrub
  policy API refuses an override that names one (`422`).
- **Variables keep their names.** A secret variable is recorded by name only. A Postman `baseUrl`
  with no safe value becomes a `{baseUrl}` server variable. Exporting back to Postman writes a secret
  variable with an empty value.
- **Auth becomes stubs.** A converted OpenAPI document lists each scheme under
  `components.securitySchemes`, as a type with no credential. Only requests that declared auth
  require it.
- **See what was redacted.** The catalog item's **Provenance** tab has a **Secret scrub** row: how
  many values were redacted, their types, and every redaction site (line, and archive member).
