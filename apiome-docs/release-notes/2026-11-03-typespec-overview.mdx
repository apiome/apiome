TypeSpec import is complete: compiling with the TypeSpec compiler, the canonical model from the
OpenAPI it emits, compiler and linter warnings in lint, versioned services with every step graded,
and the source card, CLI and fixtures.
[Import a TypeSpec API](/bring-in/typespec-import) now opens with an overview of all of it.

{/* truncate */}

- **When to use it:** any API designed in TypeSpec, one `.tsp` file or a multi-file project with its
  `tspconfig.yaml`, compiled with the standard TypeSpec libraries.
- **At a glance:** one table from importing a file or a project and tuning the emitted OpenAPI,
  through compiler warnings, versioned services and refused imports, to converting to OpenAPI and
  exporting back to TypeSpec, each linked to its section.
