Apiome is narrowing its first release to the [Catalog](/bring-in/catalog) and
[Projects](/build/projects). While those two are hardened for the MVP, the navigation rail shows six
features as **coming soon**: **Primitives & types**, **MCP servers** (with Agent access), **Export
studio**, **SDK settings**, **Style guides** and **Access audit**.

{/* truncate */}

- **Their guide pages are withdrawn** until each feature ships. They are kept in the repository,
  unchanged, and come back with the feature.
- **Pages that sent you to them now say what to do instead.** Exports use the **Export to another
  format…** dialog on Versions ([Browse and export](/getting-started/browse-and-export#export-another-format)),
  and the approval gate and the import & export quality policy are set over the REST API
  ([Reviews](/govern/reviews), [Import a specification](/bring-in/import-a-spec)).
- **The APIs are unchanged.** The REST, CLI and MCP references still document every endpoint,
  command and tool, and the MCP rule catalogs stay under [Govern](/govern).
