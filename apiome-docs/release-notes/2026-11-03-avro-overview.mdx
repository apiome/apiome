Avro import is complete: parsing with Parsing Canonical Form fingerprints, the canonical model with
every Avro 1.12 logical type, schema registry discovery, Confluent-style compatibility, the lint
pack, and the source card, CLI and fixtures.
[Import an Apache Avro schema](/bring-in/avro-import) now opens with an overview of all of it.

{/* truncate */}

- **When to use it:** the schemas behind your Kafka topics and any other Avro data, as `.avsc`
  schemas or Avro IDL, from files or straight from a Confluent-compatible schema registry.
- **At a glance:** one table from importing a file or a registry schema and mirroring a whole
  registry, through fingerprints, comparing versions by the Avro schema resolution rules and the
  lint pack, to converting to OpenAPI, exporting back to Avro and pushing to a registry, each linked
  to its section.
