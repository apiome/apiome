The admin console, the **Data browser** and **Migrations** were the last screens with colours of
their own: one light look and one dark look, whatever theme you had chosen. They now draw from the
same palette as the rest of the Control Panel. [Preferences](/workspace/preferences).

{/* truncate */}

- **Every theme reaches every screen.** Pick **High contrast**, **Solarized**, **Nord** or any other
  theme in Preferences and the admin console, Data browser and Migrations change with it.
- **Standard fields and buttons in the admin console.** Text fields are the same height as everywhere
  else, the main action on a page is the dark primary button, and **Cancel** is a quiet button
  beside it.
- **Admin dialogs behave like dialogs.** **Create New User**, **Create New Tenant**, **Edit Tenant**,
  **Add User to Tenant**, **Feature Flags** and the two property-template dialogs keep keyboard
  focus inside while they are open, close on **Esc** or a click outside, and return focus to the
  button that opened them.
- **Status colours mean one thing.** Green is success, amber is a warning, red is an error or a
  destructive action, blue is information — the same on these screens as on the others.
