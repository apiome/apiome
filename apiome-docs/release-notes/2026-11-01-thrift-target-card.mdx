The **Export** dialog's **Apache Thrift** card writes one `.thrift` file. The CLI exports the same with
`apiome export thrift`. [Where to find it](/ship/export-a-spec#thrift-from-any-source).

{/* truncate */}

- **Stable field ids.** A field that has no Thrift id gets one on its first export, and keeps it on
  every export after that. A field added later gets a new id, and a removed field's id is never
  reused, so clients built from an earlier export keep working.
- **Your Thrift exports losslessly.** An item imported from Thrift badges **lossless** and keeps its
  own ids. Any other source is **lossy**, and the fidelity report lists what Thrift does not keep.
- **Namespaces from the CLI.** Add `--option 'namespaces={"java": "com.acme"}'` to write `namespace`
  lines; the dialog offers **Include Comments**.
