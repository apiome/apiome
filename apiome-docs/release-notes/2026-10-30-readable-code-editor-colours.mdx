Code in Apiome's editors is easier to read. The **Versions** spec viewer and the other code editors
now color keys, strings, numbers and line numbers with enough contrast against the code background,
in every theme.

{/* truncate */}

- **Light theme.** Keys, strings and line numbers were too faint to meet the 4.5:1 contrast WCAG
  asks for text. They now use darker shades of the same colors.
- **Every theme.** Each syntax color and the line numbers reach 4.5:1 on the code background in
  all eight themes, and 7:1 in **High contrast**.
- **Checked on every change.** The accessibility check now opens a code editor in the light, dark
  and **High contrast** themes, so a faint color can't come back unnoticed.
