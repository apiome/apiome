Converting a catalog item to OpenAPI now says what the click will do.
[Convert to OpenAPI](/bring-in/catalog#convert-to-openapi).

{/* truncate */}

- **Convert & create Project.** The conversion preview's button names its outcome on a first
  conversion: a new, publishable OpenAPI project.
- **Re-convert.** For an item that has been converted before, the button reads **Re-convert**. A
  re-convert adds a new version to the project the item already produced; it does not create
  another one.
- **From the header.** **Convert to OpenAPI Project** (or **Re-convert to OpenAPI Project**) is
  the primary action on a catalog item's page and opens the preview. The fidelity warning and the
  low-fidelity acknowledgement are unchanged.
