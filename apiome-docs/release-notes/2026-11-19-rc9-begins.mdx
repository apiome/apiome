RC8 is complete. Everything it shipped, from the app's **What's new** and the REST API, is in the
[Apiome RC8](/release-notes/rc8) release notes. The build badge now reads `v<version> RC9`.

{/* truncate */}

- **Why:** RC9 opens. It is about **Projects** and **Catalog**, with OpenAPI 3.2 / 3.1 and
  Arazzo 1.1 first, then import and export fidelity.
- **What changes for you:** **What's new** starts again for RC9, and its dot appears once, because
  it tracks the badge you last read the notes for. The launcher's **Recently shipped** card lists
  RC9 work as it lands. For what RC8 brought, open the [Apiome RC8](/release-notes/rc8) post.
