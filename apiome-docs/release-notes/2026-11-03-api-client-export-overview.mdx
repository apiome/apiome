Collection export is complete: the Postman Collection v2.1 emitter, its fidelity pack, the Insomnia
and Bruno output modes, validation and round-trip, and the client target cards, CLI and fixtures.
[Export to an API client](/ship/export-to-an-api-client) now opens with an overview of all of it.

{/* truncate */}

- **When to export to an API client:** to hand an API to the people who call it as runnable saved
  requests, to move a collection to another client, to round-trip a collection, and to share it
  without any credential in it.
- **At a glance:** one table from the client cards and their options, through what each operation
  becomes and what a collection cannot carry, to the checks before every download, filling in the
  credentials, and the CLI.
