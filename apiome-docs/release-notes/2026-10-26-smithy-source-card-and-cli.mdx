`apiome import smithy` now takes every Smithy input the server reads: a `.smithy` file, a JSON AST,
an archive, or a model folder. [Import a Smithy model](/bring-in/smithy-import#from-the-cli).

{/* truncate */}

- **Model folders.** `apiome import smithy ./weather-model/` packs the folder's files, leaving out
  build output, and the server assembles them into one model.
- **JSON AST.** A Smithy JSON AST imports directly, with no Smithy CLI needed on the server; the
  example corpus now includes one.
- **The Smithy card** in **Import to catalog** accepts `.smithy`, `.json` and archives.
