title: The newest unchanged version reads "Latest"
description: "On the Changes tab, an unchanged newest version now reads Latest."
authors: [apiome]
---

On a project's **Changes** tab, the newest published version used to read **No changes** when
nothing changed since the version before it. It now reads **Latest**, so the top of the list says
where the project stands. Older unchanged versions still read **No changes**. See
[Changes](/build/versions#changes).
