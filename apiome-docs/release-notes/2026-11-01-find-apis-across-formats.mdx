A new page, [Find APIs across formats](/bring-in/find-apis-across-formats), puts every way to find
an API by its kind side by side, whether it came in as OpenAPI, gRPC, GraphQL, AsyncAPI or Avro.

{/* truncate */}

- **Where to look.** The Catalog's filters, **Categorize…**, search across formats and the browse
  app, each with what it is for.
- **The browse app's chips.** The **Paradigm** and **Format** chips on the organization directory
  and a project list, their counts and **Clear filters**, documented for the first time.
- **One vocabulary.** The six protocols and every spelling the REST filters accept (`grpc`,
  `graphql`, `event-driven`, `mcp` …), and why an unknown value matches nothing instead of failing.
