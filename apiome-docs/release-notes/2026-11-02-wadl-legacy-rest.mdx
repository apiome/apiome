A WADL description now imports with everything the catalog does for a modern contract: WADL's
own reuse resolved, native lint rules, a comparison that follows XML Schema's rules, and a
cleaner path to OpenAPI.
[Import WADL descriptions](/bring-in/wadl-import).

{/* truncate */}

- **Reuse resolved.** A `method`, `param` or `representation` written once and referenced with
  `href="#id"`, and a resource's `type="#…"` resource types, now read as if written inline.
  Before, a referenced method came in as a `GET` with nothing on it. A reference that names
  nothing is reported, not guessed at.
- **More of the document kept.** Sequence elements' `minOccurs` / `maxOccurs` / `nillable`
  (optional and repeated fields with their bounds), enumerated simple types (enums), a param's
  `option` values, `repeating`, `default` and `matrix` / `plain` style, every representation's
  media type, and each code of a `status="400 409"` list as its own response.
- **Lint.** The `wadl` pack flags unresolved references, undeclared or unused template params,
  duplicate or missing method ids, non-standard HTTP methods, a body on GET / HEAD / DELETE, a
  method with no response, an invalid status, an undeclared type and an untyped representation.
- **Diff.** A required param or element added, an element made required, sequence elements
  swapped, a `maxOccurs` lowered, a media type, `option` or enumeration value removed is
  breaking; an element made optional or an enumeration value added is dangerous; optional
  additions are safe.
- **Migrate to OpenAPI.** Converting a WADL item now keeps each method `id` as its
  `operationId`, every response media type and the `option` values as an `enum`, so the bundled
  task-tracker example converts at the `high` tier (it was `medium`).
- **One-time version change.** Because the stored models gained these details, the first
  re-import of an existing WADL item is recorded as a changed version.
