### Postman Collection

In **Add MCP server**, **click “Postman Collection”**, choose a collection file (`.json`) — try
`apiome-ui/examples/postman/01-tasks-collection.postman_collection.json` — or paste its JSON, and
**click “Convert to OpenAPI & Continue”**. Apiome converts it to OpenAPI 3.1 (**Converted to OpenAPI
3.1**) and carries on as a file import.
