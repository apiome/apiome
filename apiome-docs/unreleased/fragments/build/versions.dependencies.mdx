## Dependencies

The **Dependencies** tab lists what the project depends on and what depends on it — consumers,
declared dependencies, the repository that serves it — with each edge's provenance and owner team,
then draws them. **Click “Blast radius”** to see what a change to one of its operations or schemas
affects. See [Dependency graph](../govern/dependency-graph.mdx#the-dependencies-tab).
