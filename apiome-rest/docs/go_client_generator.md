# Go client generator (SDK-2.4, #4488)

`app.go_client_generator` turns a persisted `CanonicalApi` into a complete, **dependency-free**
Go module: exported types for the contract's schemas, one `context.Context`-first method per HTTP
operation, `net/http` transport behind an injectable interface, auth helpers derived from the
model's security schemes, typed errors for the declared error responses, and a runnable example
program per operation group.

It is a pure function — no clock, no environment, no filesystem — called from `app.sdk_kit`, whose
archive carries the output under `go/` (see `public_sdk_kit.md`).

## Why it generates from the canonical model

SDK-2.4's stated dependencies were the generator SPI (SDK-1.2, #4482) and the codegen
preprocessing pass (SDK-1.3, #4483). Both were closed **not-planned**, along with the artifact
store (#4481), the two MVP language generators (#4485/#4486) and the dashboard/CLI surfaces
(#4491/#4492) — so there is no SPI to register with and no sandbox to run in.

This module follows the precedent SDK-2.3, SDK-3.3 and SDK-3.4 set: read the persisted canonical
model directly, and ride the client kit rather than an artifact store. It asks
`app.snippet_render` the three questions the snippets already answer — `upper_snake_token`,
`request_message`, `pick_content_type` — so a generated method and the snippet beside it describe
the same call, and it reads auth through `app.canonical_security`, the one module that knows the
two `extras` shapes an import can record it in.

## What it emits

| File | Contents |
| --- | --- |
| `go.mod` | The module path and a `go 1.21` directive. No requirements — the client is standard-library only |
| `client.go` | `Client`, `NewClient`, the `Doer` interface, every `With…` option, and the shared request/response plumbing |
| `errors.go` | `APIError` (method, URL, status, headers, raw body), `AsAPIError`, and one typed error per declared error response |
| `auth.go` | One option per security scheme the model declares. Omitted entirely when it declares none |
| `models.go` | One exported Go type per named schema. Omitted when the contract declares none |
| `<group>.go` | One file per operation group: its `Params` structs, its methods, and its error decoders |
| `examples/<group>/main.go` | A runnable `package main` calling up to `MAX_EXAMPLE_OPERATIONS` (5) of the group's operations |
| `README.md` | `go get`, quick start, auth, errors, examples, and the operation table |

Every `.go` file carries the standard `// Code generated by Apiome. DO NOT EDIT.` marker and, when
the tenant configured one, its SDK-3.4 licence header as a leading line-comment block.

## How canonical types become Go

| Canonical kind | Go |
| --- | --- |
| `RECORD` | A struct, with `json` tags and `,omitempty` on every optional field |
| `ENUM` | A defined type over `string` / `int64` / `bool` plus one constant per member. A heterogeneous enum becomes `any` with no constants — no single underlying type fits its members |
| `UNION` | A struct holding `json.RawMessage`, with `MarshalJSON`/`UnmarshalJSON`, `Raw()` and one `As<Variant>()` accessor per resolvable variant |
| `MAP` | `map[string]T` — JSON object keys are always text, whatever the contract names as its key type |
| `ALIAS` | A Go **type alias** (`type Ref = Problem`), so the target's methods come with it. A chain that loops resolves to `any`, which Go would otherwise reject outright |
| `SCALAR` | Its underlying type from the shared scalar vocabulary, falling back to the type's own `format` and then to `any` |

Scalar widths come from `app.canonical_json_schema.CANONICAL_SCALAR_SCHEMAS` rather than a second
spelling table, so a scalar name a new import adapter starts emitting gets a Go type the moment the
fleet's shared vocabulary learns it.

**Pointering has three rules, applied in order:** a slice, a map and `any` are never pointers
(`nil` is already their absent value); a struct or a union always is; everything else is a pointer
only when the contract makes it optional. The middle rule is what lets a recursive contract — a
tree node, a threaded comment — compile at all.

## How an operation becomes a method

```go
func (c *Client) GetComment(ctx context.Context, id string, params *GetCommentParams) (*Comment, error)
```

- **Path parameters are positional**, in template order, escaped through `escapePath`. A template
  token the contract forgot to declare still becomes a `string` argument — the call cannot be made
  without it.
- **Query, header and cookie parameters share one `*<Method>Params`**, which may be `nil`. A slice
  parameter is ranged and added once per element; an optional one is nil-guarded and dereferenced.
- **A JSON request body is typed from its payload**, or `any` when the contract names no type. A
  non-JSON body is `[]byte`, sent verbatim under its declared media type rather than marshalled as
  JSON it is not.
- **The return type is the success payload**: `*T`, `[]T`, or `json.RawMessage` when the contract
  declares a body but names no type for it. An operation with no declared response returns only
  `error`.
- **Declared error responses arrive typed.** A numeric 4xx/5xx that names a payload type gets a
  Go type embedding `*APIError` with a decoded `Payload`; `errors.As` finds either. A status
  *range* (`4XX`) gets none — a `switch` on the status code has no case it could be. Two
  operations declaring the same status and body shape share one type; two declaring the same
  status with *different* bodies get two, qualified by payload.

## Auth

`app.canonical_security` distinguishes the two shapes an import can record auth in:
`operation.extras["security"]` is a per-operation **requirement**, while
`api.extras["inferred_auth_schemes"]` is only an **observation** that the API was seen using a
scheme. A client *option* is an offer rather than a per-call assertion, so this generator acts on
both — unlike the request-file emitter, which may only add a header for the operation-scoped form.

Each scheme becomes one option (`WithBearerToken`, `WithBasicAuth`, `WithAPIKey`,
`WithAuthorization`, `WithDigestAuthorization`, `WithSessionCookie`); schemes that are the same
header on the wire (`bearer`, `oauth2`, `openIdConnect`) share one. The header **name** comes from
`AUTH_SCHEME_HEADERS`, so a client's helper and a request file's header cannot disagree about
where a credential travels. A scheme with no header representation (`mutualTLS`) gets no helper
and is named in the README rather than approximated.

## Emitting Go that compiles

Go rejects several things a naive emitter produces, so the design is shaped around them:

- **Unused imports are errors**, so every file's import set is computed from what was actually
  emitted rather than written as a fixed preamble.
- **Package-level identifiers share one namespace.** Every generated type, constant, `Params`
  struct, typed error and decoder is allocated from one `_Names` seeded with the identifiers the
  fixed files define, so a schema called `Client` becomes `Client2`.
- **Filenames are allocated on the stem**, so a service called "client" becomes `client2.go` and
  never the uncompilable `client.go2`.
- **Go keywords cannot be locals**, so a path parameter named `type` becomes `typeValue`.
- **gofmt promotes an unpunctuated one-line doc paragraph to a `#` heading** (Go 1.19's comment
  reformatting). Every generated doc paragraph is therefore ended with a full stop — without that,
  a contract's one-line summary silently becomes a section title and `gofmt -l` is never clean.

## Limits and degradation

- An operation with **no HTTP binding** gets no method and is recorded in `skipped` with a reason,
  exactly as the kit records its skipped snippets.
- `max_operations` (250 from the kit, matching `MAX_KIT_OPERATIONS`) bounds the work; the rest are
  reported rather than silently dropped, and the cap counts only renderable operations.
- A **union has no discriminator** in the canonical model, so it is carried as raw JSON with typed
  accessors rather than as a tagged struct that would have to invent the tag.
- A model that records auth only as a top-level OpenAPI `security` block yields **no helper** — the
  canonical model has no first-class security field to read, and `WithHeader` covers the gap.

## The compile gate

`tests/test_go_client_generator.py` asserts the shape of the output, and its last test asserts
that the output is Go. When a Go toolchain is on `PATH` it writes a generated module to disk and
runs:

```bash
go build ./...   # compiles — what an unused import or a recursive value type would break
go vet ./...     # not obviously wrong
gofmt -l .       # formatted the way Go is written
go test ./...    # a hand-written test drives the client against a live httptest server
```

The `go test` is the closest a unit test gets to a live call: a real HTTP round trip over
localhost exercising the path, query, cookie, auth header, user-agent, JSON decoding and the typed
404. Without a toolchain the test **skips**, so the suite stays runnable everywhere.
