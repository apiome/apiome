Schedule sunset (EOL)

Set lifecycle to Deprecated, enter a required sunset date and time (stored in UTC), and optionally the successor revision (by version label) consumers should migrate to—or leave no successor for a pure end-of-life. Entries appear on the sunset timeline.

Published revision — only deprecation and sunset metadata can be changed here.

A sunset date requires Deprecated.

Required. Local time is converted to UTC for storage. To clear a sunset, use Edit version from the row menu.

Optional. Pick the replacement by version label (stored as the successor revision id), or leave as end of life with no successor.
