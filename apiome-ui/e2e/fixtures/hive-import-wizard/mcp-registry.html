Import from a registry

Bring in every server an MCP registry lists: the official registry, Azure API Center, a Kong registry or another Apiome workspace. Each server with a reachable remote is added here, discovered and graded. Servers Apiome cannot reach are listed with the reason.

The registry root. For another Apiome workspace: https://<apiome>/registry/mcp/<workspace>.

Optional — only servers whose name matches. Leave empty for every server.

The official registry and most public ones need no credential.
