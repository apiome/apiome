$ref handling
How shared objects are written. bundle (default): one file, shared objects under components, reached by $ref. dereference: one file, every $ref replaced by a copy of what it points at. split: a root file plus one file per path item and component, joined by relative $ref.
Reference cycles
With dereference, what to do with a circular $ref, which can never be fully expanded. keep-ref (default): keep the $ref that closes the loop and report it. error: refuse the export.
