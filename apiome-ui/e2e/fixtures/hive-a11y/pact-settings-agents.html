What an AI agent may do with contracts

MCP

Agents connected through Apiome’s MCP server see contracts as tools. Reading is on; anything that writes is yours to allow. A refused action tells the agent why and is written to the access audit.

Read pacts, verdicts and can-i-deploy
“Is it safe to change this field?” answered from real consumers.
Draft a pact from a project or a mock capture
Returns a draft for a person to review. Publishes nothing. No agent tool drafts pacts yet; this applies when one ships.
Publish pacts and provider contracts
Only on branches that are not a main branch. No agent tool publishes yet; this applies when one ships.
Record deployments
Never to an environment marked production.

The same, from anywhere

The same, from anywhere

PUT /v1/tenants/{tenant}/pact-contract-settings/agents

{
  "read": true,
  "draft": true,
  "publish": false,
  "record": false
}
  • Send a workspace API key as Authorization: Bearer $APIOME_API_KEY; secrets are shown as $VARIABLES.

Replace {tenant} with your workspace’s handle in the REST path.
