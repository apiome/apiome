3Check it before it counts

Compare with

One pact, several provider versions at once — you see today’s answer and tomorrow’s. Checks write nothing.

The same check, from anywhere

apiome pact check pacts/ \
  --against main
  • Reads PACT_BROKER_BASE_URL and PACT_BROKER_TOKEN, or the workspace you signed in to with apiome login.

Exits 0 when every pact matches every provider version checked, 1 otherwise. Replace {tenant} in the REST path.

The same, from anywhere

apiome pact publish pacts/ \
  --consumer-app-version '<version>'
  • Reads PACT_BROKER_BASE_URL and PACT_BROKER_TOKEN, or the workspace you signed in to with apiome login.

Replace {tenant} with your workspace’s handle in the REST path. In CI the GitHub Action fills the version and branch from the run.
