Schema registry

Defaults for schema subjects, and how Kafka serializers connect.

Settings

Used by every subject that sets no level of its own. Until compatibility rules ship, a new version under any level except NONE is refused (error 42290).

Connect a serializer

Registry URL
https://api.example.com/registry/schema/acme

Create a key under Workspace → API keys with the Schema registry: read + write preset for a producer (scopes registry:read and registry:write), or Schema registry: read for a consumer. Send it as the basic-auth password; the user name can be anything.
