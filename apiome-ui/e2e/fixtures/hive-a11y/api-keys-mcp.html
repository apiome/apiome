Use a key

Bearer token over HTTPS
curl -X POST \
  https://api.apiome.dev/v1/diff/ver_1a2b/ver_3c4d/classified \
  -H "Authorization: Bearer sk_live_…" \
  -H "Accept: application/json"

Keys are tenant-scoped: every call runs as Northwind. Rotate by creating a new key, switching the pipeline over, then deleting the old one.

Connect a host

Streamable HTTP, bearer token
URL:     https://mcp.apiome.dev/mcp
Header:  Authorization: Bearer <your-mcp-key>

Calls run as Northwind and can read its private published specs. Leave the header out to read public specs only. REST keys are not accepted here.

What a key may call

A new key calls the workspace's default MCP tools — Workspace defaults in the table. Change the defaults under MCP settings, or give one key its own set under Per-key capabilities — both in the workspace's manage drawer.

In Workspaces, click Manage on Northwind's row.
