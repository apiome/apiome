Record a deployment

Say which version is now running. It replaces the one in that instance.

A version already recorded: publishing a pact or a result records it.

For the same service running in several places.

can-i-deploy says no

  • Orders UI 3.3.2 in Production needs currency on POST /invoices; 2.7.0 does not return it.

Replaces 2.3.1.

The same, from anywhere

apiome pact record-deployment \
  --pacticipant billing-service \
  --version 2.7.0+9f31c20 \
  --environment production
  • Reads PACT_BROKER_BASE_URL and PACT_BROKER_TOKEN, or the workspace you signed in to with apiome login.

Not carried by the command

  • Record it anyway is not carried by the command (REST carries it): record-deployment does not ask can-i-deploy: in a pipeline run apiome pact can-i-deploy first. REST carries overrideCanIDeploy=true for the audit trail.

Replace {tenant} with your workspace’s handle in the REST path.
