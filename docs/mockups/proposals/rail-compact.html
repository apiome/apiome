Rail that fits 900 px

The rail on the left is the proposal — the shared shell, re-cut by the script on this page. Toggle Callouts to number the changes.

What changes
264 px · 34 px rows · footer pinned
  1. 1
    Workspace group starts collapsed. Members · Roles · API keys are admin chores, not daily work; a collapsed group shows its count and opens with one click (state already persists under hive.navCollapsed, DESIGN.md §5.2). Build / Bring in / Ship / Govern stay open.
  2. 2
    Tenants leaves the rail. It becomes the last row of the workspace switcher menu (“Manage workspaces…”), where switching already happens. The route is unchanged.
  3. 3
    Tools (Data browser · Migrations) get a home in the user menu under “Admin console”. The shipped rail already leaves them out (lib/platform-nav.ts defers the Tools group), so today they are reachable only from deep links; one menu row makes them discoverable without spending rail height. They still render in the legacy palette until P6 lands.
  4. 4
    SDK settings folds into Export studio as a tab (“SDK & branding”). Both configure how a published version leaves the system.
  5. 5
    Notifications shows a count in the footer rather than only a bell, and the footer order becomes Notifications · Help · Preferences · user.
  6. 6
    “Preview” pill → dot. The honey pill on Lint posture reads as a badge of honour on every page; a 6 px honey dot after the label says “preview” without shouting, and the tooltip carries the word.
