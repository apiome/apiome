What the pact needs, beside what Billing API 2.7.0 promises
Pact expects

  "id": integer,
  "amount": integer,
  "currency": /^[A-Z]{3}$/
}
Spec returns
{
  "id": integer,
  "amount": integer,
  "money": { "currency": … }
}
Why this matters. currency moved under money in 2.7.0 (changes). Either the consumer follows, or the provider keeps both until Orders UI ships.
