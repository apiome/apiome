Run your consumer against the hosted mock. Apiome watches what it asks for and writes the pact — no Pact library, no test rewrite.

The mock answers from the spec, so every captured call already agrees with the provider contract. The pact adds the part only you know: which of it this consumer relies on. REST, GraphQL, gRPC and event channels all record the same way.
